# SpaceIQ (SiQ)

> SpaceIQ, branded SiQ and now part of Eptura, is a workplace and space-management platform. Its GraphQL API (schema version 1.7) exposes workplace data — companies, buildings, floors, spaces, departments, employees, meeting-room calendars, hoteling desks, map images, and reports/exports — and supports creating and deleting meeting-room calendar events. All access is over HTTPS with an admin/IT-generated access token; the schema is fully introspectable.

## API
- [SiQ GraphQL endpoint](https://api.spaceiq.com/queries): Single POST GraphQL endpoint. JSON body with a "query" string. Bearer access-token auth.
- [Developer documentation](https://developer.spaceiq.com/): Full object reference, authentication, queries, and mutations.

## Model
- Objects: Company, Building, Floor, Space, Department, Employee, MapObject, AssetTag, WorkplaceGroup
- Search: BuildingSearch, FloorSearch, SpaceSearch, DepartmentSearch, EmployeeSearch, Hoteling Desks Search, Meeting Room Availability Search
- Queries: viewer, company, building, floor, space, department, employee, employeeExport, mapImage, reports, report
- Mutations: createCalendarEvent, deleteCalendarEvent

## Conventions
- Transport: HTTPS only, POST, application/json
- Auth: Authorization bearer access token (generated by Admin/IT in the SiQ web app)
- Pagination: Relay-style Connection / Edge / Node
- Timestamps: ISO 8601 (YYYY-MM-DDTHH:MM:SSZ); blank fields returned as null
- Introspection: __schema / __type supported
